# Shopping Cart

Full-stack shopping cart (product listing, cart management, JWT auth + roles) built with
React + Redux Toolkit (client) and Express + Mongoose (server), TypeScript end-to-end.

> Setup, API reference, and assumptions — _coming in a later phase_.

## Repository layout

```
shopping-cart/
├── client/   # Vite + React + Redux Toolkit + RTK Query
├── server/   # Express + TypeScript + Mongoose
└── docs/     # implementation plan (phased)
```

## Prerequisites

- Node `22.22.3` (see `.nvmrc` — run `nvm use`)
- Docker (for local MongoDB)
